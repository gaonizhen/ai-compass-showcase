# AI Office Compass · C 端 Agent 办公赛道竞品分析（2026 H2）

> 一份**每个数字都能溯源**的竞品分析：给四个 AI 办公产品出同一套考题，题里预埋标准答案抓幻觉，逐项验算打分，全程截图存证。

## 这是什么

对比对象：**豆包工作（字节）· Kimi（月之暗面）· 扣子空间（字节）· Manus（Monica/Meta）**

与常见竞品报告的区别：不用二手资料拼凑，而是把竞品分析做成了一场**可复现的实验**——

1. **出题**：5 类标准化任务（写周报 / 数据分析 / 网页生成 / 信息调研 / 修 bug），统一 prompt 逐字一致，题中预埋标准答案（销售数据 3 处、bug 代码 2 处）抓幻觉；
2. **考试**：四家产品各 20 项任务全部实测，第一期 79 张截图 + 19 份产出转录全程存证；
3. **阅卷**：每任务加权判据 0-10 分，修复代码经本地实测验证，每格得分可回溯到原始证据；
4. **写报告**：证据分级标注（A 一手 / B 官方 / C 媒体 / D 第三方估计），局限如实声明，不外推。

## 批次二（P2）：补上盲区

第一期名单评审漏掉了纯办公位选手，P2 补入 **千问办公 / WorkBuddy / ChatGPT Work（国际对照组）**，
并以**豆包工作为锚点**做跨期复测。判据先做**生态中立化改造**（中性层全体可比 / 生态层单列标注）。

**结果**（4 产品 × 5 任务 = 20/20）：**WorkBuddy 9.8 · ChatGPT Work 9.8 · 千问办公 9.7 · 豆包工作（锚点）9.4**
——补上的三家与第一期第一梯队同档，**没有出现"降维打击"**。

**P2 三个新发现**：

1. **"零依赖"四家里只有两家是真的** —— 把交付物拿回来、**阻断全部外部请求**后重开：
   WorkBuddy（内联 ECharts 的 1MB 单文件）与 ChatGPT Work 通过；
   豆包（Chart.js CDN，离线图表报错）与千问（Google Fonts，且同一段自述既称"零依赖"又称"字体加载生效"）不成立。
2. **"我自己实测过" ≠ "实测可信"** —— WorkBuddy 主动做无头浏览器自证、方法与走查一致且可复现；
   千问用**模拟 DOM** 跑出"监听器累积"并断言真实 DOM 行为，真实浏览器实验证明**同引用监听器会被去重**，该结论不成立。
3. **对话不是产物的全部边界** —— 桌面 App 把交付物写在本机磁盘（对话只给摘要），
   **只看对话截图判卷会系统性低估这类产品**。

> P2 是**独立增量报告**，不修改第一期报告的结论（数据截至日不同：第一期 2026-10-04 / P2 2026-10-06）。
> **只有豆包具备跨期对照**，其余三家为单次快照，不做稳定性外推；四家不具备可比的任务级成本数据，故不做定量成本对比。

## 三个核心判断

1. **忠实性成为分层变量** —— 同一写作任务，豆包/扣子严格只用给定数据，Kimi 为"亮点"静默虚构 4 处细节，Manus 用占位符+显式声明推断。用户极难察觉，却是企业采用的第一道信任门槛。
2. **没有全能冠军** —— 均分 8.7-9.6 高度接近，但分任务冠军完全不同；唯一全收敛的修 bug 任务说明基础能力已成标配、差异转向解释精度。"选哪家"取决于任务结构，通用横评排名正在失效。
3. **成本与组织整合重塑格局** —— 首次实测 Agent 产品的成本结构：调研任务消耗是普通任务的 5-30 倍；字节 7-8 月完成组织收编、入口集中。

## 核心数字

- 4 产品 × 5 任务 · **20/20 完成** · 第一期 79 张截图 · 19 份产出转录
- 均分：**扣子空间 9.6** > Manus 9.4 > 豆包工作 9.2 > Kimi 8.7
- 抓到的真实缺陷：Kimi 虚构 4 处 · 豆包 CDN 依赖 · 扣子日期时区 bug · Manus 国内域名不可达
- 成本实测：扣子调研任务 = 32% 积分 · Manus 修 bug（Lite 直答）= 1 积分
- P2：4 产品 × 5 任务 = 20/20 · 交付物"零依赖"机器复算 **2/4 为真** · 算术陷阱 4 家全对
